# 공통코드관리 프로세스

## 1. 화면 접속 → 코드 트리 조회

```
사용자
  ↓ 화면 접속
React (CmmnCodeList)
  ↓ GET /cmmnCode/tree?langGb=ko_KR&cmpnyCd=xxx
Backend Controller (CmmnCodeController.selectCodeTree)
  ↓ cmmnCodeService.selectCodeTree(langGb, cmpnyCd)
Service (CmmnCodeServiceImpl)
  ↓ cmmnCodeMapper.selectCodeTree(params: langGb, cmpnyCd)
Mapper (MyBatis - CmmnCodeMapper)
  ↓ SELECT ... FROM CM_CODE, CM_MESSAGE_LANG (CmmnCode_SQL_mysql.xml - selectCodeTree, WITH RECURSIVE CODE_HIERARCHY)
DB
  ↑ List<Map<String, Object>>
Mapper
  ↑ buildTree() → List<CodeTreeDTO>
Service
  ↑ IntermediateResultVO.success(result)
Controller
  ↑ JSON Response
React
  ↑ requestFetch Success → setCodeTree(treeData)
사용자 화면 (트리 렌더링)
```

## 4. 코드 등록 (추가 버튼 → 저장)

```
사용자 (저장 버튼 클릭, 추가 모드)
  ↓
React (CmmnCodeList.handleSave)
  ↓ POST /cmmnCode (body: CmmnCodeRequestDTO)
Backend Controller (CmmnCodeController.insertCode)
  ↓ cmmnCodeService.insertCode(requestDTO)
Service (CmmnCodeServiceImpl)
  ↓ cmmnCodeMapper.insertCode(params)
Mapper (MyBatis - CmmnCodeMapper)
  ↓ INSERT INTO CM_CODE (insertCode)
DB
  ↑ (PK 중복 시 DataIntegrityViolationException / isDuplicateKeyException → CmmnCodeDuplicateKeyException)
Service
  ↑ throw CmmnCodeDuplicateKeyException(duplicateKey: CODE_ID or DETAIL_CODE_ID, duplicateDetailIndex)
Controller
  ↑ catch → resultCode 900, resultMessage, result: { duplicateKey, duplicateDetailIndex }
React
  ↑ resultCode 900 시 알림 + 해당 컬럼 포커스 (#codeDetail_codeId / #codeDetailList_{index}_detailCodeId)

  ↓ 정상 시:
Service
  ↓ codeDetailList 있으면: deleteCodeDetail → insertCodeDetail (각 행 PK 중복 시 동일 예외 처리)
Mapper
  ↓ INSERT INTO CM_CODE_DETAIL (insertCodeDetail)
DB
  ↑
Service
  ↑
Controller
  ↑ IntermediateResultVO.success(null)
React
  ↑ requestFetch Success → retrieveCodeTree(), retrieveCodeDetail()
사용자 화면 (트리/상세 갱신)
```

## 5. 코드 수정 (저장 버튼 클릭, 수정 모드)

```
사용자 (저장 버튼 클릭, 수정 모드)
  ↓
React (CmmnCodeList.handleSave)
  ↓ PUT /cmmnCode/{codeId} (body: CmmnCodeRequestDTO)
Backend Controller (CmmnCodeController.updateCode)
  ↓ cmmnCodeService.updateCode(codeId, requestDTO)
Service (CmmnCodeServiceImpl)
  ↓ cmmnCodeMapper.updateCode(params)
Mapper (MyBatis - CmmnCodeMapper)
  ↓ UPDATE CM_CODE (updateCode)
DB
  ↑
  ↓ deleteCodeDetail → insertCodeDetail (코드리스트 재등록, 행별 PK 중복 시 CmmnCodeDuplicateKeyException)
Service
  ↑ throw 시 Controller catch → resultCode 900, result: { duplicateKey, duplicateDetailIndex }
React
  ↑ resultCode 900 시 알림 + 해당 컬럼 포커스

  ↓ 정상 시:
Mapper
  ↓ DELETE FROM CM_CODE_DETAIL / INSERT INTO CM_CODE_DETAIL
DB
  ↑
Service
  ↑
Controller
  ↑ IntermediateResultVO.success(null)
React
  ↑ requestFetch Success → retrieveCodeDetail()
사용자 화면 (상세/리스트 갱신)
```

## 6. 코드 삭제

```
사용자 (삭제 버튼 클릭)
  ↓
React (CmmnCodeList.handleDelete)
  ↓ GET /cmmnCode/checkChildren?codeId=xxx&cmpnyCd=xxx
Backend Controller (CmmnCodeController.checkChildren)
  ↓ cmmnCodeService.checkChildren(codeId, cmpnyCd)
Service (CmmnCodeServiceImpl)
  ↓ cmmnCodeMapper.checkChildren(params)
Mapper (MyBatis - CmmnCodeMapper)
  ↓ SELECT ... FROM CM_CODE WHERE UPPER_CODE_ID = #{codeId} (checkChildren)
DB
  ↑ "O" or "X"
  ↑ 하위 있으면 "X" → React에서 삭제 중단

  ↓ 하위 없으면: DELETE /cmmnCode/{codeId}?cmpnyCd=xxx
Backend Controller (CmmnCodeController.deleteCode)
  ↓ cmmnCodeService.deleteCode(codeId, cmpnyCd)
Service (CmmnCodeServiceImpl)
  ↓ cmmnCodeMapper.deleteCodeDetail(params) → cmmnCodeMapper.deleteCode(params)
Mapper (MyBatis - CmmnCodeMapper)
  ↓ DELETE FROM CM_CODE_DETAIL / DELETE FROM CM_CODE
DB
  ↑
Controller
  ↑ IntermediateResultVO.success(null)
React
  ↑ requestFetch Success → retrieveCodeTree(), 상태 초기화
사용자 화면 (트리 갱신)
```

## API·DB 요약

| 구분 | API | Controller 메서드 | Service 메서드 | Mapper 메서드 | DB 테이블 |
|------|-----|-------------------|----------------|---------------|-----------|
| 코드 트리 | GET /cmmnCode/tree?langGb=&cmpnyCd= | selectCodeTree | selectCodeTree | selectCodeTree | CM_CODE, CM_MESSAGE_LANG |
| 코드 상세 | GET /cmmnCode/detail?codeId=&langGb=&cmpnyCd= | selectCodeDetail | selectCodeDetail | selectCodeDetail | CM_CODE, CM_MESSAGE_LANG |
| 코드 리스트 | GET /cmmnCode/detailList?codeId=&langGb=&cmpnyCd= | selectCodeDetailList | selectCodeDetailList | selectCodeDetailList | CM_CODE_DETAIL, CM_MESSAGE_LANG |
| 상위코드 조회 | GET /cmmnCode/parent?codeId=&langGb=&cmpnyCd= | selectParentCode | selectParentCode | selectParentCode | CM_CODE, CM_MESSAGE_LANG |
| 코드 등록 | POST /cmmnCode | insertCode | insertCode | insertCode, insertCodeDetail | CM_CODE, CM_CODE_DETAIL |
| 코드 수정 | PUT /cmmnCode/{codeId} | updateCode | updateCode | updateCode, deleteCodeDetail, insertCodeDetail | CM_CODE, CM_CODE_DETAIL |
| 코드 삭제 | DELETE /cmmnCode/{codeId}?cmpnyCd= | deleteCode | deleteCode | deleteCodeDetail, deleteCode | CM_CODE_DETAIL, CM_CODE |
| 하위 존재 확인 | GET /cmmnCode/checkChildren?codeId=&cmpnyCd= | checkChildren | checkChildren | checkChildren | CM_CODE |

**비고**

- **회사코드(cmpnyCd)**: 트리/상세/리스트/상위코드/삭제/하위확인 API에서 쿼리 파라미터로 사용. 트리는 `WITH RECURSIVE`로 회사별 계층 조회.
- **언어 목록**: 공통코드 화면에서 사용하는 언어 옵션은 **GET /cmmnMessage/languages** (CmmnMessage 매퍼 selectLanguages) 단일 소스 사용.
- **등록/수정 시 PK 중복**: CM_CODE PK `(CMPNY_CD, CODE_ID)`, CM_CODE_DETAIL PK `(CMPNY_CD, CODE_ID, DETAIL_CODE_ID)` 중복 시 Service에서 `CmmnCodeDuplicateKeyException` 발생 → Controller가 resultCode **900**, result `{ duplicateKey, duplicateDetailIndex }` 반환 → React에서 알림 후 해당 입력란 포커스.
