# 다국어관리 프로세스

## 1. 화면 접속 → 회사 목록·구분·언어 조회 후 메시지 리스트 조회

```
사용자
  ↓ 화면 접속
React (CmmnMessageList)
  ↓ GET /cmmnMessage/companies (회사 목록)
Backend Controller (CmmnMessageController.selectCompanyList)
  ↓ cmmnMessageService.selectCompanyList(loginUserId)
Service (CmmnMessageServiceImpl)
  ↓ cmmnMessageMapper.selectCompanyList(params)
Mapper (MyBatis - CmmnMessageMapper)
  ↓ SELECT ... FROM CM_GROUP_USER, CM_USER_ORGNZT_MBRSH, CM_CMPNY (CmmnMessage_SQL_mysql.xml - selectCompanyList)
DB
  ↑ List<CmmnCompanyOptionDTO>
  ↓ GET /cmmnMessage/categories (구분 목록)
  ↓ GET /cmmnMessage/languages (언어 목록)
  ↓ GET /cmmnMessage/list?langGb=...&cmpnyCd=...&category=...&searchCondition=...&pageIndex=...&recordCountPerPage=...
Backend Controller (CmmnMessageController.selectMessageList)
  ↓ cmmnMessageService.selectMessageList(langGb, cmpnyCd, category, searchCondition, pageIndex, recordCountPerPage)
Service (CmmnMessageServiceImpl)
  ↓ cmmnMessageMapper.selectMessageList(params), selectMessageListCount(params)
Mapper (MyBatis - CmmnMessageMapper)
  ↓ SELECT ... FROM CM_MESSAGE_LANG, CM_CODE_DETAIL (selectMessageList, selectMessageListCount)
DB
  ↑ List<Map>, Integer
Mapper
  ↑ convertToDTOList() → CmmnMessageListResponseDTO
Service
  ↑ IntermediateResultVO.success(result)
Controller
  ↑ JSON Response
React
  ↑ requestFetch Success → setCompanyList, setMessageList, pagination
사용자 화면 (목록·페이징 표시)
```

## 2. 목록 행 선택 → 메시지 상세 조회

```
사용자 (목록 행 클릭)
  ↓
React (CmmnMessageList 또는 상세 화면 진입)
  ↓ GET /cmmnMessage/detail?langKey=xxx&langGb=ko_KR&cmpnyCd=...
Backend Controller (CmmnMessageController.selectMessageDetail)
  ↓ cmmnMessageService.selectMessageDetail(langKey, langGb, cmpnyCd)
Service (CmmnMessageServiceImpl)
  ↓ cmmnMessageMapper.selectMessageDetail(params)
Mapper (MyBatis - CmmnMessageMapper)
  ↓ SELECT ... FROM CM_MESSAGE_LANG (selectMessageDetail)
DB
  ↑ CmmnMessageDetailResponseDTO (langGb, langKey)
  ↓ cmmnMessageMapper.selectMessageDetailMessages(params)
Mapper
  ↓ SELECT ... FROM CM_CODE_DETAIL, CM_MESSAGE_LANG (selectMessageDetailMessages)
DB
  ↑ List<MessageDetailDTO>
Mapper
  ↑ result.setMessages(messages)
Service
  ↑ IntermediateResultVO.success(result)
Controller
  ↑ JSON Response
React
  ↑ requestFetch Success → setCodeDetail / 폼 표시
사용자 화면 (상세 폼·언어별 메시지 표시)
```

## 3. 메시지 등록 (추가 → 저장)

```
사용자 (추가 버튼 → 폼 입력 → 저장)
  ↓
React (CmmnMessageEdit)
  ↓ POST /cmmnMessage (body: CmmnMessageRequestDTO)
Backend Controller (CmmnMessageController.insertMessage)
  ↓ cmmnMessageService.insertMessage(requestDTO)
Service (CmmnMessageServiceImpl)
  ↓ requestDTO.getMessages() 루프: cmmnMessageMapper.insertMessage(params)
Mapper (MyBatis - CmmnMessageMapper)
  ↓ INSERT INTO CM_MESSAGE_LANG (insertMessage)
DB
  ↑
Service
  ↑
Controller
  ↑ IntermediateResultVO.success(null)
React
  ↑ requestFetch Success → 목록으로 이동 또는 갱신
사용자 화면 (등록 완료)
```

---

## 4. 메시지 수정 (상세에서 수정 → 저장)

```
사용자 (상세 화면에서 수정 후 저장)
  ↓
React (CmmnMessageEdit)
  ↓ PUT /cmmnMessage/{langKey} (body: CmmnMessageRequestDTO)
Backend Controller (CmmnMessageController.updateMessage)
  ↓ cmmnMessageService.updateMessage(langKey, requestDTO)
Service (CmmnMessageServiceImpl)
  ↓ cmmnMessageMapper.deleteMessageByLangKey(deleteParams)
Mapper (MyBatis - CmmnMessageMapper)
  ↓ DELETE FROM CM_MESSAGE_LANG (deleteMessageByLangKey)
DB
  ↑
  ↓ insertMessage(requestDTO) (동일 로직으로 재등록)
Mapper
  ↓ INSERT INTO CM_MESSAGE_LANG (insertMessage)
DB
  ↑
Service
  ↑
Controller
  ↑ IntermediateResultVO.success(null)
React
  ↑ requestFetch Success → 상세 재조회 또는 목록 갱신
사용자 화면 (수정 완료)
```

## 5. 메시지 삭제

```

  ↓
React (CmmnMessageList)

Backend Controller (CmmnMessageController.deleteMessage)
  ↓ cmmnMessageService.deleteMessage(requestDTO)
Service (CmmnMessageServiceImpl)
  ↓ langKeys 루프: cmmnMessageMapper.deleteMessageByLangKey(params)
Mapper (MyBatis - CmmnMessageMapper)
  ↓ DELETE FROM CM_MESSAGE_LANG (deleteMessageByLangKey)
DB
  ↑
Service
  ↑
Controller
  ↑ IntermediateResultVO.success(null)
React
  ↑ requestFetch Success → retrieveMessageList()
사용자 화면 (목록 갱신)
```
